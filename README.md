# Coffeescript Perfil

Projeto de estudo em CoffeeScript que cria uma classe `Perfil` 
com nome e cargo, usando o método `descrever()` para exibir 
as informações do colaborador.

## Como rodar
1. Instale o CoffeeScript: `npm install --global coffeescript`
2. Compile: `coffee -c User.coffee`
3. Execute: `node User.js`
